# Classification: CiteSync.dev — Product Requirements Document

- **Source:** docs/CiteSync.dev — Product Requirements Document.md
- **Type:** PRD
- **Precedence:** 3 (PRD — after ADR=1, SPEC=2)
- **Sections:** 96 (§1–§96)
- **Language:** English

## Decisions

1. **D-PRD-01:** CiteSync is a linter, not an academic writing assistant (§3)
2. **D-PRD-02:** Deterministic-first architecture — same document + same version = same result (§65)
3. **D-PRD-03:** No LLM dependency in core application (§66)
4. **D-PRD-04:** Offline-first — core parser MUST NOT depend on remote resources (§11)
5. **D-PRD-05:** Privacy by default — no document upload, no manuscript storage, no account, no cloud DB (§10)
6. **D-PRD-06:** DOCX-only for v0.1, PDF excluded (§12, §68)
7. **D-PRD-07:** MIT license target (§1 header)
8. **D-PRD-08:** Monorepo package architecture — apps/web, packages/core|docx|citations|references|matcher|rules|report|cli (§47)
9. **D-PRD-09:** UI never directly parses academic documents — always via core API (§92)
10. **D-PRD-10:** Core package (@citesync/core) MUST NOT depend on React, Next.js, browser DOM, server runtime, UI libraries (§46)
11. **D-PRD-11:** Source files < 400 lines per file (§94)
12. **D-PRD-12:** Evidence MUST NOT be generated by LLM (§42)
13. **D-PRD-13:** Citations supported: author-date + numeric families (§18–19)
14. **D-PRD-14:** Initial styles: APA-like, Harvard-like, IEEE-like, Vancouver-like (§7)
15. **D-PRD-15:** Structured citation metadata prioritized over text heuristics (§22)
16. **D-PRD-16:** Bibliography detection MUST return confidence; MUST NOT silently guess (§17)
17. **D-PRD-17:** Severity model: ERROR, WARNING, AMBIGUOUS, INFO (§38)
18. **D-PRD-18:** Fuzzy matches MUST produce warnings unless confidence is sufficiently high (§25)

## Requirements

1. **R-PRD-01:** Check every in-text citation has bibliography entry (§1)
2. **R-PRD-02:** Check every bibliography entry is cited in document (§1)
3. **R-PRD-03:** Detect ambiguous/inconsistent author-year references (§1)
4. **R-PRD-04:** Validate numeric citations correctly mapped to bibliography (§1)
5. **R-PRD-05:** Parse DOCX as OOXML packages — word/document.xml, styles.xml, footnotes.xml, endnotes.xml (§14)
6. **R-PRD-06:** Common internal document model AcademicDocument (§15)
7. **R-PRD-07:** Source mapping — every citation/reference retains original location (§16)
8. **R-PRD-08:** Bibliography detection with confidence scoring (§17)
9. **R-PRD-09:** Author normalization — case folding, Unicode, punctuation, diacritics (§24)
10. **R-PRD-10:** Matching engine with weighted scoring (§26)
11. **R-PRD-11:** Lint rules CS001–CS010 (§28–37)
12. **R-PRD-12:** Core report with summary counts (§39)
13. **R-PRD-13:** Results UI — desktop layout with issues + document panels (§40)
14. **R-PRD-14:** Issue interaction — click to scroll-to-source + highlight + evidence (§41)
15. **R-PRD-15:** Evidence panel — explain why each issue exists (§42)
16. **R-PRD-16:** User corrections for ambiguity — session-only, no DOCX modification (§43)
17. **R-PRD-17:** Export report — JSON, HTML; optional Markdown (§45)
18. **R-PRD-18:** CLI — `npx citesync file.docx` (§49)
19. **R-PRD-19:** PWA — installable, offline shell, cached parser (§57)
20. **R-PRD-20:** Performance — 100-page DOCX < 3 seconds (§55)
21. **R-PRD-21:** Web Worker for heavy parsing, UI stays responsive (§12, §55)
22. **R-PRD-22:** Browser support — Chrome, Edge, Firefox, Safari (§56)
23. **R-PRD-23:** Rule extensibility — CiteSyncRule interface (§52)
24. **R-PRD-24:** Configuration via .citesyncrc (§51)
25. **R-PRD-25:** CLI exit codes 0/1/2/3 (§50)
26. **R-PRD-26:** Security — no macros, no embedded execution, no remote URLs, zip bomb protection, XML size limits, processing time limits (§87)
27. **R-PRD-27:** Failure isolation — malformed citation MUST NOT crash analysis (§88)
28. **R-PRD-28:** Accessibility — keyboard nav, focus states, screen-reader labels, non-color severity indicators (§89)
29. **R-PRD-29:** Vietnamese bibliography heading support required (§54)
30. **R-PRD-30:** Benchmark dataset with reproducible fixtures (§74–76)
31. **R-PRD-31:** Quality targets — citation detection precision ≥98%, recall ≥95%, reference matching precision ≥97% (§78)
32. **R-PRD-32:** Anonymous product analytics allowed (application opened, analysis started/completed, etc.) (§10)
33. **R-PRD-33:** Analytics MUST NOT include document text, citation text, author names, reference titles, file names, bibliography contents (§10)
34. **R-PRD-34:** Session state is local-only; document disappears when user clears session; no persistence required (§44)
35. **R-PRD-35:** README shows product immediately with recommended section sequence (§81)

## Constraints

1. **C-PRD-01:** No server dependency (§86)
2. **C-PRD-02:** No database dependency (§86)
3. **C-PRD-03:** No mandatory WASM runtime (§86)
4. **C-PRD-04:** No large ML models (§86)
5. **C-PRD-05:** No API keys (§86)
6. **C-PRD-06:** No vendor-specific AI services (§86)
7. **C-PRD-07:** Document max 50MB recommended initial (§12)
8. **C-PRD-08:** Desktop-first, mobile secondary (§56)
9. **C-PRD-09:** UI English only for v0.1 (§54)
10. **C-PRD-10:** v0.1 scope excludes: PDF, Google Docs extension, Word plugin, reference verification, DOI lookup, Crossref/OpenAlex, LLM, AI writing, plagiarism, grammar, citation formatting, bibliography generation, auto-editing, accounts, cloud, collaboration, document history (§8)
